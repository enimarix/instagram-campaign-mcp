# Assets in motion/

Every file under `public/`, with its licence and source; `test/assets-licenses.test.ts` fails
when a file is missing here or a listed file is gone. Third-party licence texts sit next to the
files. Our own files are generated by `scripts/make-assets.ts` (`node scripts/make-assets.ts`
from `motion/`): sprites from `src/lib/sprites.ts`, audio from its square/triangle/noise synth.
