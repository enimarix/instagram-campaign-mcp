# Assets in motion/

Every file under `public/`, with its licence and source; `test/assets-licenses.test.ts` fails
when a file is missing here or a listed file is gone. Third-party licence texts sit next to the
files. Our own files are generated by `scripts/make-assets.ts` (`node scripts/make-assets.ts`
from `motion/`): sprites from `src/lib/sprites.ts`, audio from its square/triangle/noise synth (and its sine marimba, kalimba and glockenspiel voices), and the mastered stereo beds from `scripts/beds.ts` (step 148).

Press Start 2P covers Latin-1 and Latin Extended-A (all but ŉ, Ţ, ţ), plus Greek and
Cyrillic. Romanian comma-below Ș ș are missing (Ț ț and cedilla Ş ş are there). Design size 8 px: use whole multiples.
"Press Start 2P" is a Reserved Font Name: a modified copy must be renamed.
